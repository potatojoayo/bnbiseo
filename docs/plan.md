# 비엔비서 (BnBiseo) 서비스 기획서

> **최종 수정일**: 2026-04-10
> **문서 버전**: v3.0
> **작성 목적**: MVP 개발 및 초기 사업 검증을 위한 종합 서비스 기획서

---

## 1. 서비스 개요

### 한 줄 정의

**비엔비서는 에어비앤비 전문 청소·시설관리 서비스로, "청소"를 진입점 삼아 숙소 데이터를 축적하고, 수리·소모품·컨설팅까지 확장하는 호스트 전용 공간 케어 플랫폼이다.**

### 비전

> "부업인데 왜 본업보다 스트레스 받으시나요?"

에어비앤비 호스팅을 진정한 '패시브 인컴'으로 만든다. 청소·시설관리·게스트 응대에 드는 시간과 스트레스를 없애는 것이 최종 목표.

### 미션

서울 에어비앤비 호스트가 청소 매니저 관리, 시설 점검, 긴급 대응에 쓰는 시간과 비용을 80% 이상 절감한다.

## 2. 문제 정의

### 2.1 핵심 페인 포인트

에어비앤비 호스트, 특히 부업으로 1~5채를 운영하는 호스트는 다음의 구조적 문제에 직면한다.

| 문제 영역 | 구체적 상황 | 비용/시간 손실 |
|-----------|------------|---------------|
| **청소 매니저 리스크** | 당일 체크인인데 청소 매니저가 갑자기 펑크 | 호스트가 직접 뛰어가거나 게스트 불만 발생 |
| **시설 고장 긴급 대응** | 해외출장 중 보일러 고장, 잠금장치 오류 | 원격 대응 불가, 건당 2~3배 비용 |
| **반복적 게스트 대응** | 보일러 사용법, 쓰레기 분리수거 등 동일 질문 반복 | 호스트당 하루 30분~1시간 |
| **비품 규격 파편화** | 이불솜 g수, 수건 장수, 건조기 사양을 매번 카톡방에 질문 | 정보 탐색에 매번 시간 소모 |
| **수리비 바가지** | 비대면 관계 특성 이용, 적정가 이상 요구 | 수리 건당 30~65% 과다 지출 |

### 2.2 문제의 구조적 원인

1. **청소-시설관리 분리**: 청소 매니저는 청소만, 수리는 별도 업체 → 숙소 상태를 통합 관리하는 주체가 없음
2. **공간 데이터의 부재**: 숙소 시설물의 규격, 모델, 설치일 등이 체계적으로 기록되지 않아 매번 처음부터 파악
3. **수리 시장의 비효율**: 소규모 건 위주라 비교 기준이 없고, 호스트는 적정가를 알 수 없음

### 2.3 문제 검증 근거

- **정성 검증**: 에어비앤비 호스트 카카오톡 오픈채팅방(2,700명) 대화 분석 결과, 시설 고장/수리 대응, 청소 매니저 펑크, 게스트 반복 문의가 가장 빈번한 주제 (상세: `docs/kakao-chat-analysis.md`)
- **실사용 검증 예정**: 서울 내 10채를 운영하는 호스트에 MVP 적용, 실사용 피드백으로 검증

## 3. 솔루션

### 3.1 핵심 전략: 청소를 진입점으로, 데이터로 확장

**표면**: 에어비앤비 호스트를 위한 전문 청소·시설관리 서비스
**이면**: 청소 매니저가 매번 숙소에 진입하며 시설 데이터를 자연스럽게 축적 → 수리, 소모품 배송, 컨설팅으로 객단가 극대화

```
[청소 서비스 진입]           [데이터 축적]              [서비스 확장]
호스트 숙소 정보 등록        매 청소마다 시설 점검      수리/유지보수 제안
긴급/정기 청소 매칭    →    15개 항목 체크리스트   →   소모품 자동 배송
호텔식 세팅 차별화          사진 리포트 전송           데이터 기반 컨설팅
```

### 3.2 서비스 라인업

#### 클린 케어 (Day 1 — 핵심 진입 서비스)

| 서비스 | 설명 | 가격 |
|--------|------|------|
| **표준 청소** | 에어비앤비 전문 호텔식 세팅 + 시설 점검 리포트 | 35,000원~ (면적/침구 기준) |
| **긴급 청소** | 당일 요청, 매니저 펑크 대응 | 별도 할증 |
| **특수 청소** | 흡연 냄새 제거, 해충 대응 후 청소 | 별도 견적 |

> **핵심 가치: 긴급 상황에서의 확실한 대응.** 이모님이 갑자기 펑크 내도 급하게 이리저리 사람을 찾을 필요 없이, 할증 금액만 추가하면 당일 매니저가 투입된다. 호스트에게 필요한 건 "싼 가격"이 아니라 "급할 때 확실히 되는 것".

#### 시설 케어 (Month 3~ — 마진 확장)

| 서비스 | 설명 | 가격 |
|--------|------|------|
| **청소 시 발견 하자 수리** | 점검 리포트에서 발견된 문제 → 승인 시 다음 방문에 수리 | 건별 견적 |
| **긴급 수리 대응** | 해외출장 중 보일러 고장 등 | 건별 견적 |
| **예방 점검** | 비수기 전 시설물 종합 점검 | 50,000원~ |

#### 데이터 케어 (Month 6~ — 락인 강화)

| 서비스 | 설명 |
|--------|------|
| **소모품 자동 배송** | 세제, 수건, 어메니티 등 소모 패턴 기반 정기 배송 |
| **디지털 트윈 관리** | 숙소 시설물 규격/모델/이력 통합 관리 대시보드 |
| **운영 컨설팅** | 데이터 기반 가격 전략, 시설 투자 제안 |

### 3.3 비엔비서만의 약속 (차별화)

1. **긴급 대응 보장**: 이모님이 펑크 나도 이리저리 사람 찾을 필요 없습니다. 할증만 내면 당일 매니저가 출동합니다.
2. **데이터 기반 케어**: 숙소 정보를 한 번만 등록하세요. 주소, 쓰레기장 위치, 비밀번호... 매번 설명할 필요 없습니다.
3. **확실한 리포트**: 청소 전/후 사진과 시설 점검표를 앱으로 즉시 전송합니다.

### 3.4 시설 점검 체크리스트 (15개 항목)

매 청소 완료 시 매니저가 점검하여 사진과 함께 호스트에게 리포트 전송:

| 카테고리 | 점검 항목 |
|----------|----------|
| **조명** | 전구 점등 여부, 전구 교체 필요 여부 |
| **수전/배관** | 수전 누수, 배수 상태 |
| **도어락** | 배터리 잔량, 작동 상태 |
| **보일러** | 에러코드 여부, 온도 정상 작동 |
| **에어컨** | 필터 상태, 냉방/난방 작동 |
| **가전** | 세탁기/건조기/인덕션 작동 상태 |
| **환기** | 욕실/주방 환기팬 작동 |
| **소모품** | 세제/휴지/어메니티 잔량 |
| **기타** | 벽/타일 손상, 가구 파손, 해충 흔적 |

> 이 체크리스트가 곧 디지털 트윈 데이터의 기초가 된다. "청소업체"가 아니라 "내 자산을 관리해 주는 업체"라는 인식을 심는 핵심 무기.

### 3.5 숙소 정보 등록 (무료)

"보험" 포지셔닝: 청소를 당장 맡기지 않더라도, 숙소 정보만 무료로 등록해두면 긴급 상황 시 터치 한 번으로 당일 매니저 출동.

등록 정보:
- 숙소 주소, 도어락 비밀번호
- 쓰레기장 위치, 분리수거 요일
- 침구 수량, 주요 시설물 정보
- 에어비앤비 리스팅 URL (선택)

> 이 무료 등록이 이탈률 0%의 DB 수집 전략. 등록만 해두면 긴급 시 바로 대응 가능하므로 호스트 입장에서 손해가 없다.

## 4. 타겟 시장

### 4.1 시장 규모

| 구분 | 정의 | 규모 (추정) | 산출 근거 |
|------|------|------------|----------|
| **TAM** | 한국 전체 단기임대 숙소 청소·시설관리 시장 | 약 3,000억원/년 | 전국 등록 숙박업소 약 6만개 x 연간 청소+시설관리비 평균 500만원 |
| **SAM** | 서울 에어비앤비 호스트 청소·시설관리 수요 | 약 500억원/년 | 서울 활성 리스팅 약 15,000개 x 연평균 330만원 |
| **SOM** | 서비스 런칭 후 1년 내 확보 가능 시장 | 약 1.5억원/년 | 마포구/종로구 집중, 10~30채 관리 |

### 4.2 ICP (Ideal Customer Profile)

**1순위: 부업 호스트 (1~3채)**

- 본업이 있어 직접 대응 불가 (해외출장 중 고장 등)
- 청소 매니저 관리에 스트레스
- "보험처럼" 등록해두는 것에 거부감 없음
- 카카오톡 호스트 커뮤니티 분석에서 가장 활발한 세그먼트

**2순위: 다채 호스트 (5채+)**

- 이미 수익의 25%를 대행에 지출 (커뮤니티 실거래 기준)
- 풀오토 운영 니즈 → 비용 절감 어필
- 1명 확보 = 5채+ 일감 확보

### 4.3 초기 거점

**마포구 (홍대/연남)** 또는 **종로구** 중 1곳 집중

- 에어비앤비 밀집 지역
- 매니저 이동 동선 최소화
- 입소문 효과 극대화

## 5. 경쟁 분석

### 5.1 경쟁 환경

| 경쟁자 유형 | 대표 서비스 | 강점 | 약점 | 비엔비서와의 관계 |
|------------|-----------|------|------|-------------------|
| **에어비앤비 청소 업체** | 지역 "이모님" 네트워크 | 가격 저렴, 관계 기반 | 펑크 리스크, 시설 점검 없음, 대체 불가 | **직접 경쟁** |
| **청소 매칭 플랫폼** | 청소연구소, 미소 | 넓은 매니저 풀 | 에어비앤비 특화 아님, 호텔식 세팅 모름 | **직접 경쟁** |
| **숙소 관리 대행** | 에어호스트 등 | 풀서비스 | 월 매출의 15~25% 수수료 | **간접 경쟁** (상위 시장) |
| **수리 매칭 플랫폼** | 숨고, 크몽 | 넓은 기사 풀 | 숙소 규격 모름, 매번 처음부터 | **간접 경쟁** (수리 영역) |

### 5.2 차별화 핵심

1. **긴급 대응 보장**: 할증만 내면 당일 매니저 투입. 급하게 사람 찾아 헤맬 필요 없음.
2. **에어비앤비 전문**: 호텔식 세팅, 체크아웃~체크인 사이 "마의 4시간" 대응
3. **시설 점검 리포트**: 단순 청소가 아니라 "자산 관리" → 타 업체로 전환 비용 발생
4. **데이터 축적**: 매 방문마다 시설 데이터가 쌓여 수리 제안·소모품 자동화로 확장

## 6. 비즈니스 모델

### 6.1 초기 BM: 단건 요청, 단건 결제

최대한 단순하게 운영한다. 구독, 월정액, 패키지 없이 **요청 1건 = 결제 1건**.

| 서비스 | 가격 | 비고 |
|--------|------|------|
| 표준 청소 | 35,000원~ | 면적·침구 수량 기준 |
| 긴급 청소 (당일) | 별도 할증 | |
| 수리 (Month 3~) | 건별 견적 | 청소 중 발견된 하자 or 별도 요청 |

> **핵심 가치는 "급할 때 확실히 되는 것".** 할증은 있지만, 급하게 이리저리 사람을 찾아 헤맬 필요 없이 할증 금액만 내면 바로 해결된다. 호스트에게 필요한 건 싼 가격이 아니라 안정적인 운영.
>
> 구독/월정액은 고객이 쌓이고 이용 패턴이 보인 뒤 설계한다.

#### 런칭 이벤트

1. 숙소 정보 등록 시 첫 청소 10,000원 할인
2. 웰컴메시지 엽서 & 조화 침대 세팅 무료 진행

### 6.3 10채 관리 시 수익 시뮬레이션

**가정**: 에어비앤비 가동률 70%, 숙소당 월 ~12회 체크아웃, 총 월 120건 청소

| 항목 | 금액 |
|------|------|
| 청소 매출 | 4,410,000원 (표준 108건 + 긴급 12건) |
| 세제/소모품/이동비 | -300,000원 |
| **청소 순이익** | **~4,100,000원** |
| 수리 추가 이익 (Month 3~) | +150,000~400,000원 |
| **종합 순이익** | **~4,250,000~4,500,000원** |

> 초기에는 창업자가 직접 청소하므로 매니저 인건비 0원. 10채만으로도 월 400만원+ 순이익. 생활비를 확보하면서 동시에 고객 기반을 쌓는 구조.

### 6.4 손익분기점

| 규모 | 운영 체제 | 월 순이익 | 의미 |
|------|----------|----------|------|
| 10채 | 창업자 직접 | ~400만원 | 생활비 확보 + 고객 기반 구축 |
| 20채 | 창업자 + 매니저 1명 | ~350만원 | 매니저 채용 시점 (체력 한계) |
| 30채 | 창업자 + 매니저 1명 | ~450만원 | 안정 궤도 |
| 50채 | 매니저 2~3명 | ~550~700만원 | 사업 궤도, 창업자는 운영/영업에 집중 |

## 7. 운영 전략

### 7.1 청소 운영

#### Phase 1: 창업자 직접 청소 (~20채)

초기에는 창업자가 직접 청소를 수행한다. 이유:

- **매니저 인건비 0원** → 건당 매출이 그대로 순이익
- **오퍼레이션 체감** → 현장에서 문제점과 개선점을 직접 발견
- **시설 점검 품질** → 창업자가 직접 하면 체크리스트 완성도가 높음
- **고객 신뢰** → "사장이 직접 온다"는 것 자체가 초기 신뢰 구축

하루 처리량: 3~4건 (이동 포함), 마의 4시간(11시~15시) 집중

#### Phase 2: 매니저 채용 (20채~)

체력 한계 또는 영업/개발에 시간이 필요해지면 매니저 채용.

- 창업자가 직접 만든 SOP와 체크리스트로 교육
- 초기 1~2주는 동행하며 품질 검증

#### 인력 확장 계획

| 단계 | 관리 숙소 | 운영 체제 |
|------|----------|----------|
| Phase 1 | ~20채 | 창업자 직접 |
| Phase 2 | ~30채 | 창업자 + 매니저 1명 |
| Phase 3 | ~50채 | 매니저 2~3명, 창업자는 운영/영업 집중 |

#### "마의 4시간" 문제 (Phase 3~)

에어비앤비 청소는 체크아웃(11시)~체크인(15시) 사이에만 수요 집중. 매니저가 하루 1~2건이면 수입이 안 되어 이탈.

**해결**: 파티룸/렌탈 스튜디오(이른 오전, 늦은 밤), 소형 오피스(출근 전, 퇴근 후) 청소 병행으로 매니저 하루 스케줄을 채워 월 300만원+ 수입 보장.

> Phase 1~2에서는 창업자가 직접 하므로 이 문제가 발생하지 않는다. 매니저 채용 후 검토.

### 7.2 수리 운영 (Month 3~)

창업자가 직접 청소 + 수리를 모두 담당. 청소하면서 하자를 발견하고, 직접 수리까지 이어지는 원스톱 구조.

**청소 + 수리 번들 흐름**:
```
청소 중 시설 점검 → 하자 발견 → 리포트에 기록
         ↓
호스트에게 수리 견적 자동 전송 → 승인
         ↓
다음 방문 시 수리 (또는 긴급 별도 방문)
```

> 청소 1건(마진 8,000원)이 수리 1건(마진 30,000~50,000원)으로 자연 확장. 이것이 "청소 회사"에서 벗어나는 핵심.

#### 수리 인력 확장

| 단계 | 숙소 수 | 수리 인력 | 월 인건비 |
|------|---------|----------|----------|
| ~40채 | ~40채 | 창업자 직접 | 0원 |
| 40~50채 | 50채 | 계약직 1명 채용 | 280~320만원 |
| 50~100채 | 100채 | 2명 체제 (지역 분할) | 560~640만원 |
| 100채+ | 100채+ | 핵심 기사 2~3명 + 전문 외주 | 하이브리드 |

### 7.3 락인 전략

| 전략 | 설명 | 효과 |
|------|------|------|
| **시설 점검 리포트** | 매 청소마다 15항목 체크리스트 → "자산 관리" 인식 | 타 업체 전환 시 이 데이터를 잃음 |
| **숙소 정보 축적** | 도어락 비밀번호, 쓰레기장, 비품 규격 등 | 새 업체에 다시 설명해야 하는 비용 |
| **3D 스캔** | 6개월 월정액 고객에게 Polycam 스캔 지원 | 예약률 향상 + 시설 DB로 활용 |
| **수리 이력** | 시설물별 수리 이력이 쌓일수록 예방 정비 정확도 향상 | 장기 사용 가치 증가 |

### 8.2 단계별 전략

#### Phase 1: 10채 확보 (Month 1~3)

| 전략 | 실행 |
|------|------|

| **커뮤니티 침투** | 호스트 카페/오픈톡방에 "청소 매뉴얼 & 시설 점검 체크리스트(엑셀)" 무료 배포 → 하단에 비앤비서 링크 |

- 카톡 오픈채팅방 방장 승인 하에 서비스 소개 (이미 에어컨 청소, 방역 등 업체 홍보 관행 있음)

#### Phase 3: 50채+ (Month 7~12)

- 정기 고객 사례/후기 콘텐츠 마케팅
- 레퍼럴 프로그램 (추천 시 양쪽 1회 청소 무료)
- 랜딩 페이지 2개 체제 (에어비앤비 전문 / 파티룸·스튜디오 전문)

### 8.3 초기 영업 무기

**무료 배포 콘텐츠**: "에어비앤비 청소 매뉴얼 & 시설 점검 체크리스트" (엑셀/PDF)

- 실용적 가치 제공으로 신뢰 구축
- 하단에 비앤비서 로고 + "마포구 한정 베타테스트 1만 원 할인" 링크
- 카페/오픈톡방에 자연스럽게 공유 가능

### 8.4 메시징

| 상황 | 메시지 |
|------|--------|

## 10. 리스크 & 대응

### 10.1 핵심 리스크

| 리스크 | 영향도 | 발생 확률 | 대응 |

- 매니저 이탈로 서비스 장애가 월 2회 이상이면 운영 구조 재설계

## 부록

### A. 기존 자산 활용 계획

기존에 설계한 디지털 트윈, AI 챗봇, QR 시스템은 클린 케어의 백엔드 인프라로 그대로 활용:

| 기존 자산 | 클린 케어에서의 활용 |
|----------|---------------------|
| 디지털 트윈 스키마 | 시설 점검 데이터 저장 구조 |
| AI 챗봇 (Claude) | 수리 접수 챗봇, 게스트 가이드 |
| QR 게스트 가이드 | 호스트에게 추가 가치 제공 (차별화 요소) |
| 온보딩 플로우 | 숙소 정보 등록 플로우로 전환 |
| 호스트 대시보드 | 청소 이력 + 점검 리포트 + 수리 이력 통합 |

### B. 카카오톡 호스트 커뮤니티 분석 요약

상세: `docs/kakao-chat-analysis.md`
