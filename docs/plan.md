# 비엔비서 (BnBiseo) 서비스 기획서

> **최종 수정일**: 2026-04-04
> **문서 버전**: v2.0
> **작성 목적**: MVP 개발 및 초기 투자 유치를 위한 종합 서비스 기획서

---

## 1. 서비스 개요

### 한 줄 정의

**비엔비서는 에어비앤비 숙소를 "디지털 트윈(Digital Twin)"화하여, 시설 관리-게스트 응대-수리 조율을 AI로 자동화하는 호스트 전용 공간 관리 대행 서비스이다.**

### 비전

> "부업인데 왜 본업처럼 하시나요?"

에어비앤비 호스팅을 진정한 '패시브 인컴'으로 만든다. 숙소 운영에 드는 시간을 **주 10시간에서 주 1시간 이하**로 줄이는 것이 최종 목표.

### 미션

서울 내 에어비앤비 호스트가 시설 관리와 게스트 대응에 쓰는 시간과 비용을 80% 이상 절감한다.

## 2. 문제 정의

### 2.1 핵심 페인 포인트

에어비앤비 호스트, 특히 부업으로 1~5채를 운영하는 호스트는 다음의 구조적 문제에 직면한다.

| 문제 영역 | 구체적 상황 | 비용/시간 손실 |
|-----------|------------|---------------|
| **정보의 비대칭** | 수리 업자가 비대면 관계 특성을 이용해 적정가 이상을 요구 | 수리 건당 30~65% 과다 지출 (추정) |
| **반복적 대응** | 게스트가 바뀔 때마다 동일한 이용법/하자 설명 반복 | 호스트당 하루 30분~1시간 소요 |
| **비싼 긴급 수리** | 체크인 직전 고장 시 웃돈 주고 급하게 수리 | 건당 2~3배 비용 발생 |
| **규격 파편화** | 숙소마다 수전, 전구, 보일러 규격이 전부 다름 | 매번 현장 방문 후 사진 촬영 필요 |
| **전문지식 부족** | 적정 수리 가격 판단, 부품 호환성 확인 어려움 | 불필요한 전체 교체 등 과잉 수리 |

### 2.2 문제의 구조적 원인

1. **OTA 채널의 한계**: 에어비앤비는 예약 중개에 집중하며, 숙소 운영/관리 도구는 제공하지 않음
2. **공간 데이터의 부재**: 숙소 시설물의 규격, 모델, 설치일 등이 체계적으로 기록되지 않아 매번 처음부터 파악해야 함
3. **수리 시장의 비효율**: 소규모 건 위주라 수리 업체 입장에서 단가가 맞지 않고, 호스트 입장에서는 비교 기준이 없음

### 2.3 문제 검증 근거

**아직 검증되지 않았다.** 에어비앤비 3채를 운영하는 친구의 숙소에 MVP를 적용하고, 실제로 유용하다고 느끼는지가 검증이다. 커뮤니티 데이터나 설문이 아닌, 실사용자 1명의 진짜 반응이 가장 믿을 만한 근거.

## 3. 솔루션

### 3.1 핵심 컨셉: 숙소의 디지털 트윈(Digital Twin)

숙소의 모든 시설물(조명, 수전, 보일러, 가전, 잠금장치 등)을 디지털로 기록하고, 이 데이터를 기반으로 **AI가 수리 접수, 게스트 응대, 비용 산출을 자동으로 처리**한다.

### 3.2 서비스 흐름: 3단계 프로세스

```
[1단계: 공간 스캔]          [2단계: AI 접수]           [3단계: 방문 수리]
전문가 방문                 채팅으로 접수              부품 지참 방문
시설물 규격 기록     →      AI가 부품·비용 산출   →    1회 방문 해결
디지털 트윈 생성            방문 예약 자동 잡기        출장비 무료
(등록비 무료)
```

### 3.3 양면 가치 제공

#### Host-Side (호스트 대시보드)

| 기능 | 설명 | 핵심 가치 |
|------|------|----------|
| **숙소 디지털 트윈** | 시설물 규격, 모델, 설치일, 교체 이력 관리 | 규격 파악 시간 제로화 |
| **AI 수리 접수 챗봇** | "전구 나갔어요" 한마디로 부품+비용+일정 자동 산출 | 수리 접수 시간 반나절 → 3분 |
| **수리비 비교/보장** | 시장가 대비 구독 회원가 제공, 업계 최저가 보장 | 수리비 55~65% 절감 |
| **예방 정비 알림** | 설치일 기반 교체 주기 알림 (보일러 점검, 필터 교체 등) | 긴급 수리 발생률 감소 |
| **게스트 문의 자동 응답 현황** | QR 챗봇 이용 통계, FAQ 분석 | 반복 문의 대응 자동화 |

#### Guest-Side (QR 코드 기반 AI 숙소 가이드)

| 기능 | 설명 | 핵심 가치 |
|------|------|----------|
| **시설 이용법 안내** | 보일러, 세탁기, 인덕션 등 해당 숙소 맞춤 가이드 | 게스트 만족도 향상 |
| **하자 접수** | 게스트가 직접 하자를 신고하면 AI가 자동 분류 후 호스트에 전달 | 신속한 하자 대응 |
| **주변 정보** | 맛집, 편의점, 교통 등 숙소 주변 정보 제공 | 게스트 경험 개선 → 리뷰 향상 |
| **다국어 지원** | AI 기반 자동 번역 (한/영/중/일) | 외국인 게스트 대응 자동화 |

### 3.4 수리 운영 구조

#### 수리기사 커버리지

초기에는 공동 창업자(에어비앤비 3채 운영 + 수리 경험 보유)가 직접 수리를 담당한다.

| 항목 | 수치 |
|------|------|
| 1일 처리량 (이동 포함) | 3~4건 |
| 월간 처리량 (22일 근무) | 약 70~90건 |
| 커버 가능 숙소 (월 1.5건/채 기준) | **약 40~50채** |

#### 수리 인력 확장 전략: 직접 채용 (계약직)

**핵심 원칙: 수리 품질 = 비엔비서의 제품 품질.** SaaS에서 서버를 외주 주지 않는 것처럼, 수리 오퍼레이션은 비엔비서의 핵심 인프라이므로 직접 통제해야 한다.

**외주/파트너 네트워크를 택하지 않는 이유:**
- 수리비의 60~70%를 외주 기사에게 지급하면 비엔비서 마진이 30~40%로 축소 (수익 모델 붕괴)
- "1회 방문 해결 + 디지털 트윈 업데이트"라는 핵심 가치를 외부 기사에게 기대하기 어려움
- 외주 중개만 하면 숨고/크몽과 차별화 불가

**단계별 인력 계획:**

| 단계 | 숙소 수 | 수리 인력 | 월 인건비 |
|------|---------|----------|----------|
| Phase 1 (친구 숙소) | 3채 | 창업자 직접 | 0원 |
| Phase 2 (지인 영업) | ~40채 | 창업자 직접 (여유 있음) | 0원 |
| 40~50채 돌파 | 50채 | **계약직 1명 채용** | 280~320만원 |
| Phase 3 (확장) | 50~100채 | 2명 체제 (지역 분할) | 560~640만원 |
| 100채+ | 100채+ | 핵심 기사 2~3명 + **전문 외주** (보일러, 에어컨 등) | 하이브리드 전환 |

**계약직을 택하는 이유 (정규직 대비):**
- 4대보험 부담 경감 (월 40~50만원 차이)
- 초기 스타트업 리스크 관리 (사업 피벗 시 유연한 인력 조정)
- 우수 기사는 정규직 전환 인센티브로 리텐션

**채용 시 요건:**
- 다기능 필수 (배관 + 전기 + 소가전 기본기)
- 창업자가 Phase 1~2에서 문서화한 SOP로 온보딩
- 전문 수리(보일러 정밀 점검, 에어컨 냉매 충전 등)는 100채+ 시점에서 검증된 외주 풀 구성

**비수기 고정비 대응:**
- 예방 점검 서비스 패키지 판매로 기사 가동률 유지
- 연간 구독 할인으로 비수기 이탈 방지

> Phase 2까지는 창업자 1명으로 충분하다. **50채 도달 2~3개월 전부터 채용을 시작**하여 공백 없이 전환한다.

#### 수리비 절감 구조

비엔비서가 수리비를 낮출 수 있는 구조적 이유와 **단계별 실현 가능 시점**:

| 절감 요인 | 설명 | 실현 시점 |
|----------|------|----------|
| **부품 사전 파악** | 디지털 트윈으로 호환 부품 미리 확인 → 1회 방문 해결 | Phase 1부터 즉시 |
| **출장비 구조 개선** | 구독료에 출장비 포함(무료화) | Phase 2 (유료 구독 시작 시) |
| **수요 집중** | 동일 지역 수리 건을 묶어 기사 단가 협상 | Phase 3 (50채+ 규모) |
| **직접 부품 조달** | 규격 데이터 기반 대량 구매 → 부품 마진 확보 | Phase 3 (수백 건 규모) |

**단계별 절감률 (현실적 추정)**:

| 단계 | 절감률 | 주요 절감 요인 |
|------|--------|--------------|
| Phase 1~2 (초기 ~30채) | **20~30%** | 부품 사전 파악 + 재방문 불필요 |
| Phase 3 (50채+) | **40~65%** | 위 + 수요 집중 + 대량 구매 |

| 항목 | 시장 평균가 (추정) | 초기 회원가 (Phase 1~2) | 목표 회원가 (Phase 3) |
|------|-------------------|----------------------|---------------------|
| 수전 교체 | 80,000원 | 56,000~64,000원 | 32,000원 |
| 전구 교체 | 35,000원 | 24,000~28,000원 | 12,000원 |
| 보일러 점검 | 110,000원 | 77,000~88,000원 | 50,000원 |
| 잠금장치 수리 | 100,000원 | 70,000~80,000원 | 40,000원 |

> **주의**: 시장가는 숨고/크몽 평균가 기반 추정. Phase 1에서 실제 수리 건을 수행하며 검증 필요. 랜딩페이지의 절감률(55~65%)은 규모 확장 후 목표치이며, 초기에는 20~30% 절감이 현실적이다.

### 3.5 공간 스캔 프로토콜

숙소 디지털 트윈의 핵심인 "공간 스캔"의 구체적 실행 계획:

#### 기본 정보

| 항목 | 내용 |
|------|------|
| **수행자** | Phase 1~2: 창업팀이 직접 방문. Phase 3: 호스트 셀프 스캔 앱 도입 검토 |
| **소요 시간** | 원룸/투룸: 약 1시간, 방 3개 이상: 약 1.5~2시간 |
| **필요 도구** | 스마트폰 (사진 촬영), 줄자, 스캔 체크리스트 앱 |

#### 시설물별 기록 필드

| 카테고리 | 기록 항목 | 예시 |
|---------|----------|------|
| **조명** | 위치, 종류, 브랜드/모델, 규격(소켓, 와트), 사진 | 거실 천장 LED, 삼성 SI-L60R1, E26 소켓 |
| **수전/배관** | 위치, 종류, 브랜드/모델, 규격(구경), 사진 | 주방 싱크대, 대림바스 DL-C2021, 구경 15A |
| **보일러** | 위치, 브랜드/모델, 설치일, 최근 점검일, 사진 | 베란다, 경동나비엔 NCB354, 2022년 설치 |
| **가전** | 위치, 종류, 브랜드/모델, 사진 | 주방 인덕션, 쿠쿠 CIR-F301FW |
| **잠금장치** | 위치, 종류, 브랜드/모델, 사진 | 현관, 삼성 SHP-DP960 |
| **기타** | 에어컨, 세탁기, 건조기, 환기팬 등 | 동일 구조 |

#### 스캔 순서

1. 현관 진입 → 잠금장치, 신발장
2. 각 방 순회 → 조명, 에어컨, 콘센트 상태
3. 주방 → 수전, 가전, 환기팬
4. 욕실 → 수전, 변기, 환기팬, 보일러 (해당 시)
5. 베란다/유틸리티 → 세탁기, 건조기, 보일러
6. 전체 사진 촬영 (방별 전경 + 시설물 근접)

> Phase 1에서 친구 숙소 3채를 스캔하며 프로토콜을 다듬는다. 실제로 해보면 불필요한 필드, 누락된 항목이 드러날 것이므로 이 문서는 살아있는 문서로 운영한다.

## 4. 타겟 시장 분석

### 4.1 TAM / SAM / SOM

| 구분 | 정의 | 규모 (추정) | 산출 근거 |
|------|------|------------|----------|
| **TAM** | 한국 전체 단기 임대 숙소 시설 관리 시장 | 약 3,000억원/년 | 전국 등록 숙박업소 약 6만개 x 연간 시설관리비 평균 500만원 |
| **SAM** | 서울 에어비앤비 호스트 중 시설 관리 니즈가 있는 시장 | 약 500억원/년 | 서울 에어비앤비 활성 리스팅 약 15,000개 (AirDNA 추정) x 연평균 시설관리비 330만원 |
| **SOM** | 서비스 런칭 후 2년 내 확보 가능 시장 | 약 15억원/년 | 서울 에어비앤비 호스트 500명 x 연간 구독+수리 매출 300만원 |

> **검증 필요**: AirDNA 또는 에어비앤비 공개 데이터로 서울 활성 리스팅 수 정확히 확인 필요. 2024년 기준 약 12,000~18,000개로 추정.

### 4.2 고객 세그먼트

| 세그먼트 | 숙소 수 | 비중 (추정) | 특성 | 핵심 니즈 |
|----------|---------|------------|------|----------|
| **소규모 부업 호스트** | 1~2채 | 60% | 직장인 겸업, 기술 리터러시 중간, 가격 민감 | 수리비 절감, 간편한 수리 접수 |
| **중규모 전업 호스트** | 3~10채 | 30% | 전업 또는 주요 수입원, 운영 효율 중시 | 다숙소 통합 관리, 게스트 자동 응대, 시간 절약 |
| **대규모 전문 호스트/관리업체** | 10채+ | 10% | 법인 또는 전문 관리업체, 체계적 운영 | API 연동, 커스텀 리포트, 대량 할인 |

### 4.3 ICP (Ideal Customer Profile) - MVP 단계

**1순위 타겟: 서울 소재 중규모 전업 호스트 (3~10채)**

- **인구통계**: 30~50대, 에어비앤비 수입이 월 300만원 이상
- **행동 특성**: 숙소 관리에 주 10시간 이상 투입, 수리 업체를 직접 찾아 비교하는 데 피로감
- **기술 수준**: 스마트폰 능숙, 카카오톡/네이버 카페 활발 이용
- **지불 의사**: 월 5~15만원 수준의 관리 비용에 합리적이라 판단

**선정 이유**:
- 숙소가 3채 이상이면 시설 규격 파편화 문제가 급격히 심화 → Pain Point가 강함
- 구독료 대비 절감 효과가 명확히 체감됨 (월 1~2건 수리만 해도 ROI 양수)
- 커뮤니티 내 영향력이 있어 입소문 효과 기대

## 5. 경쟁 분석

### 5.1 경쟁 환경 매핑

| 경쟁자 유형 | 대표 서비스 | 강점 | 약점 | 비엔비서와의 관계 |
|------------|-----------|------|------|-----------------|
| **수리 매칭 플랫폼** | 숨고, 크몽 | 넓은 수리기사 풀, 리뷰 시스템 | 숙소 규격 모름 → 매번 처음부터, 에어비앤비 특화 아님 | **직접 경쟁** (수리 영역) |
| **에어비앤비 코호스트** | 에어비앤비 자체 기능 | 플랫폼 내 통합, 무료 | 시설 관리 기능 없음, 인력 매칭에 그침 | **간접 경쟁** |
| **숙소 관리 대행업체** | 마이리얼트립 호스팅, 에어호스트 등 | 풀서비스 (청소, 체크인, 관리) | 월 매출의 15~25% 수수료, 시설 관리는 부가 서비스 | **간접 경쟁** (상위 시장) |
| **OTA/채널 관리** | 야놀자 클라우드, 온다 | 예약/채널 통합 관리 | 시설 관리 기능 전무, 대형 숙박업소 타겟 | **보완 관계** |
| **홈 IoT/스마트홈** | 삼성 스마트싱스 등 | 실시간 모니터링 | 설치 비용 높음, 에어비앤비 특화 아님 | **미래 잠재 경쟁** |

### 5.2 포지셔닝 맵

```
                    높은 기술 수준 (AI/자동화)
                           ▲
                           │
                           │    ★ 비엔비서
                           │    (AI + 숙소 특화)
                           │
    넓은 타겟 ◄────────────┼────────────► 숙소 특화
                           │
         숨고/크몽          │     관리대행업체
         (범용 수리 매칭)    │     (인력 기반 풀서비스)
                           │
                           ▼
                    낮은 기술 수준 (수동/인력)
```

### 5.3 차별화 핵심: "숙소를 기억하는 AI"

기존 서비스는 매번 **"어떤 숙소의 어떤 제품이 고장났는지"를 처음부터 설명**해야 한다. 비엔비서는 숙소의 디지털 트윈을 보유하고 있으므로:

1. **"전구 나갔어요" 한마디면** → AI가 해당 숙소의 거실 전구 모델(삼성 SI-L60R1)을 이미 알고 있음 → 호환 부품+비용 즉시 산출
2. **게스트가 "보일러 안 켜져요"라고 하면** → AI가 해당 숙소의 보일러 모델(경동나비엔 NCB354) 기반 맞춤 가이드 제공
3. **수리기사가 방문 전 이미 정확한 부품을 지참** → 1회 방문 해결률 극대화

이것은 단순 수리 매칭이 아니라 **"공간 데이터 기반의 관리 자동화"**이며, 데이터가 쌓일수록 경쟁 우위가 강화되는 **네트워크 효과+데이터 모트(Data Moat)**이다.

### 6.2 가격 티어

> **Free plan을 두지 않는 이유**: 온보딩에 직접 방문(공간 스캔 1~2시간)이 필요하고, 수리도 창업자가 직접 담당하는 구조에서 무료 사용자까지 커버하면 과부하. 초기 GTM이 지인 1:1 영업이므로 기능 제한된 무료 플랜보다 **첫 달 무료 체험(Trial)** 이 더 효과적.

| 플랜 | 월 구독료 | 포함 숙소 | 핵심 기능 | 수리 혜택 |
|------|----------|----------|----------|----------|
| **Standard** | **첫 달 무료** → 49,000원/월 | 3채까지 | 디지털 트윈, AI 수리 접수, 수리비 비교, 게스트 QR 가이드 (다국어) | **구독 회원가** (시장가 대비 20~65% 절감), 출장비 무료 |
| **Pro** | **첫 달 무료** → 99,000원/월 | 10채까지 | Standard + 예방 정비 알림, 수리 이력 리포트, 우선 배정 | **구독 회원가** + 월 1회 정기 점검 포함 |
| **Enterprise** | 별도 협의 | 무제한 | Pro + API 연동, 커스텀 대시보드, 전담 매니저 | 대량 할인 별도 협의 |

**첫 달 무료 체험의 장점**:
- 지인에게 "한 달 써보고 결정해"라고 제안 가능 → 영업 부담 감소
- 전체 기능을 체험하므로 가치를 제대로 느낌 (기능 제한 Free와 다름)
- 무료 기간에 실제 수리 1~2건 경험 → 절감 효과 체감 → 자연스러운 유료 전환
- Free/Standard 기능 분리 개발 불필요 → 복잡성 제거

**가격 설정 근거**:
- Standard 49,000원: 월 1건 수전 교체만 해도 약 48,000원 절감 → 구독료 즉시 회수
- Pro 99,000원: 숙소 10채 운영 시 월 수리비 평균 50~100만원 → 절감 효과로 구독료의 3~5배 회수

### 6.3 유닛 이코노믹스 (Unit Economics)

#### 단계별 CAC (고객 획득 비용)

첫 달 무료 체험 후 유료 전환율을 감안한 **실질 CAC**이 핵심이다. 단계별��� CAC이 크게 다르므로 분리하여 계산한다.

| 단계 | 온보딩 비용 | 마케팅비 | 체험→유료 전환율 | **실질 CAC** |
|------|-----------|---------|----------------|-------------|
| Phase 1~2 (지인 영업) | 80,000원 | ≈0원 (직접 제안) | 70~80% (추정) | **100,000~115,000원** |
| Phase 3 (커뮤니티 확장) | 80,000원 | 70,000원 | 50~60% (추정) | **250,000~300,000원** |

> **마케팅비 70,000원 산출 근거**: 네이버 카페 활동 + 인스타/유튜브 콘텐츠 제작 비용 + 레퍼럴 인센티브(1개월 무료 49,000원의 가중 평균). SaaS B2B 디지털 마케팅 CAC 평균(10~15만원)보다 낮게 잡은 것은 QR 바이럴 루프의 자연 유입을 감안한 수치.
>
> 지인 영업 시 마케팅비가 거의 없고 전환율도 높아 실질 CAC이 낮다. 커뮤니티 확장 시에는 마케팅비 증가 + 전환율 하락으로 CAC이 2배 이상 올라간다.

#### 전제 조건 (추정치, 실 운영 데이터로 검증 필요)

**Phase 1~2 기준 (지인 영업, 실질 CAC 약 110,000원)**:

| 지표 | Best | Base | Worst | 근거 |
|------|------|------|-------|------|
| **ARPU** | 80,000원 | 80,000원 | 65,000원 | Standard 49,000원 + 수리 마진 31,000원. Worst는 수리 빈도 감소 반영 |
| **실질 CAC** | 100,000원 | 110,000원 | 115,000원 | 온보딩 80,000원 + 마케팅≈0원, 전환율 70~80% |
| **Gross Margin** | 55% | 55% | 50% | 구독: 85% 마진, 수리: 30% 마진. Worst는 수리 마진 하락 반영 |
| **Monthly Churn** | 5% | 7% | 10% | 비수기(11~2월) "왜 돈 내지?" 심리로 이탈률 상승 가능 |
| **LTV** | 880,000원 | 629,000원 | 325,000원 | ARPU x GM x (1/Churn) |
| **LTV:CAC** | **8.8:1** | **5.7:1** | **2.8:1** | SaaS 기준 3:1 이상이면 양호 |
| **Payback** | 2.3개월 | 2.5개월 | 3.5개월 | CAC / (ARPU x GM) |

**Phase 3 기준 (커뮤니티 확장, 실질 CAC 약 270,000원)**:

| 지표 | Best | Base | Worst |
|------|------|------|-------|
| **실질 CAC** | 250,000원 | 270,000원 | 300,000원 |
| **LTV:CAC** | **3.5:1** | **2.3:1** | **1.1:1** |
| **Payback** | 5.7개월 | 6.1개월 | 9.2개월 |

> **핵심 인사이트**: 지인 영업 단계에서는 유닛 이코노믹스가 매우 건전하다. 커뮤니티 확장 단계에서는 Base/Worst 시나리오에서 LTV:CAC이 3:1 미만으로 떨어지므로, **확장 전에 전환율을 높이거나(제품 개선), 온보딩 비용을 낮추는(셀프 스캔 도입) 것이 필수**다.

#### 손익분기점 시나리오

| 시나리오 | 유료 고객 수 | 월 매출 | 월 고정비 (추정) | 월 변동비 (부품+온보딩) | 월 손익 |
|---------|------------|--------|----------------|----------------------|--------|
| **BEP (손익분기)** | 150~180명 | 12,000,000~14,400,000원 | 13,000,000원 | 1,200,000~1,400,000원 | ±0원 |
| **안정 운영** | 300명 | 24,000,000원 | 16,000,000원 | 2,400,000원 | +5,600,000원 |
| **성장 단계** | 500명 | 40,000,000원 | 22,000,000원 | 4,000,000원 | +14,000,000원 |

> **고정비 구성 (BEP 기준)**: 운영 인건비 3명 5,000,000원 + 수리기사 계약직 2명 6,000,000원 + 사무실/인프라 800,000원 + AI/서버 비용 700,000원 + 기타 500,000원
> **변동비**: 부품비 (수리 건당 평균 15,000~25,000원) + 온보딩 방문 비용

## 7. 핵심 가치 제안 (JTBD 프레임워크)

### 7.1 Jobs-to-be-Done

#### Job 1: "숙소에 문제가 생겼을 때, 빠르고 합리적인 가격으로 해결하고 싶다"

- **현재 해결 방식**: 숨고/크몽에서 업체 찾기, 지인 소개, 네이버 검색
- **불만족 포인트**: 매번 규격 설명, 가격 비교 피로, 급할 때 바가지
- **비엔비서의 해결**: AI가 규격을 이미 알고 있으므로 한마디로 접수 → 최저가 보장 → 1회 방문 해결

#### Job 2: "게스트 문의에 일일이 대응하지 않고도 높은 리뷰 점수를 유지하고 싶다"

- **현재 해결 방식**: 직접 메시지 답변, 체크인 가이드 PDF 제작
- **불만족 포인트**: 시간 소요, 다국어 대응 불가, 숙소별 맞춤 어려움
- **비엔비서의 해결**: QR 스캔 → 해당 숙소 맞춤 AI 가이드 (다국어) → 24시간 자동 응대

#### Job 3: "여러 숙소의 시설 상태를 한눈에 파악하고 체계적으로 관리하고 싶다"

- **현재 해결 방식**: 엑셀, 노션, 머릿속 기억
- **불만족 포인트**: 숙소가 늘면 관리 불가, 교체 시기 놓침
- **비엔비서의 해결**: 디지털 트윈으로 전 숙소 시설물 통합 관리 → 예방 정비 알림

### 7.2 가치 제안 우선순위

| 순위 | 가치 제안 | JTBD | 전환 영향도 | 리텐션 영향도 |
|------|----------|------|-----------|-------------|
| 1 | **AI 수리 접수 + 최저가 보장** | Job 1 | 매우 높음 | 높음 |
| 2 | **게스트 QR AI 가이드** | Job 2 | 높음 | 매우 높음 |
| 3 | **숙소 디지털 트윈 관리** | Job 3 | 중간 | 높음 |
| 4 | **예방 정비 알림** | Job 1+3 | 낮음 | 매우 높음 |

**인사이트**: 수리 접수가 전환(Acquisition)의 핵심 드라이버이고, 게스트 QR 가이드가 리텐션(Retention)의 핵심 드라이버이다. 두 기능의 조합이 비엔비서의 경쟁 우위를 만든다.

## 10. 성장 전략 (Product-Led Growth)

### 10.1 PLG vs SLG 판단

**결론: PLG 중심, SLG 보완**

| 기준 | PLG 적합도 | 근거 |
|------|-----------|------|
| 제품 체험 가능성 | 높음 | 첫 달 무료 체험으로 전체 기능 경험 가능 |
| 셀프 서비스 가능성 | 중간 | 온보딩(공간 스캔)에 오프라인 방문 필요 → 완전 셀프서비스 아님 |
| 바이럴 요소 | 높음 | 게스트 QR 스캔 → 호스트가 아닌 게스트가 제품을 경험 → 바이럴 루프 |
| ACV (연간 계약 가치) | 중간 | Standard 기준 연 588,000원 → PLG 적합 범위 |

### 10.2 QR 바이럴 루프 설계

이것이 비엔비서의 **가장 강력한 성장 엔진**이다.

```
호스트 A가 비엔비서 가입
        ↓
숙소에 QR 코드 배치
        ↓
게스트 B가 QR 스캔 → AI 숙소 가이드 이용
        ↓
게스트 B가 다른 에어비앤비 숙소에서 "여기는 왜 이런 서비스 없지?"
        ↓
게스트 B가 호스트 C에게 리뷰로 "QR 가이드 좋았어요" 언급
  또는 게스트 B가 본인도 호스트라면 비엔비서 가입
        ↓
호스트 C가 비엔비서에 관심 → 가입
```

**핵심 지표**:
- QR 스캔율: 숙소 방문 게스트 대비 QR 스캔 비율 (목표: 10~15%, 배치 위치와 안내 문구에 크게 좌우됨)
- 바이럴 계수(k): 1명의 호스트가 가져오는 신규 호스트 수 (목표: 0.3+)
- "QR 가이드" 리뷰 언급률: 게스트 리뷰에서 가이드 관련 언급 비율

### 10.3 리텐션 루프

```
[월간 리텐션 루프]
수리 발생 → AI 즉시 대응 → 비용 절감 체감 → 구독 유지
     ↑                                        ↓
예방 정비 알림 ← 디지털 트윈 데이터 축적 ← 수리 이력 기록
```

**리텐션 강화 전략**:
1. **스위칭 코스트**: 숙소 데이터(디지털 트윈)가 쌓일수록 이탈 비용 증가
2. **습관 형성**: 수리 접수를 비엔비서 챗봇으로 하는 습관 → 다른 채널로 돌아가기 어려움
3. **가치 증가**: 수리 이력이 쌓일수록 예방 정비 정확도 향상, 비용 예측 정확도 향상

### 10.4 비수기 리텐션 정책

비수기(11~2월)에는 수리 수요가 줄어 "왜 돈 내지?" 심리가 발생할 수 있다. 이를 방지하기 위한 구체적 정책:

| 정책 | 내용 | 효과 |
|------|------|------|
| **연간 구독 할인** | 12개월 선결제 시 2개월 무료 (17% 할인). Standard 연 490,000원, Pro 연 990,000원 | 비수기 이탈 원천 차단, 현금흐름 안정화 |
| **구독 일시정지** | 비수기에 숙소 운영을 중단하는 호스트에게 최대 2개월 일시정지 허용 (연 1회) | 해지 대신 정지 → 성수기 자동 복귀 유도 |
| **비수기 예방 점검 패키지** | 비수기에 전 시설물 종합 점검 + 소모품 교체 (Pro 플랜 포함, Standard는 별도 50,000원) | 비수기에도 서비스 가치 체감, 수리기사 가동률 유지 |
| **성수기 대비 리포트** | 지난 시즌 수리 이력 기반 "성수기 전 점검 추천 리스트" 자동 발송 | 비수기에도 서비스가 일하고 있다는 인식 유지 |

> **목표**: 연간 구독 비율 40%+ 달성 시 비수기 churn을 연평균 5% 이하로 관리 가능 (추정)

### 11.2 법률/규제 대응

QR을 통해 게스트 데이터를 수집하고, AI가 숙소 시설물 정보를 처리하는 서비스이므로 **MVP 단계부터** 다음을 설계에 반영해야 한다.

| 이슈 | 영향 | MVP 필수 조치 |
|------|------|-------------|
| **개인정보처리방침** | 게스트 문의 내용, QR 접속 로그 수집 | 서비스 이용 전 동의 화면 필수. 개인정보처리방침 문서 작성 |
| **외국인 게스트 (GDPR)** | EU 게스트의 데이터 처리 시 GDPR 적용 가능 | 데이터 최소 수집 원칙, 삭제 요청 대응 기능, 동의 절차 다국어화 |
| **숙소 주소 = 개인정보** | 호스트의 숙소 주소가 개인정보에 해당 | 주소 암호화 저장, 접근 권한 최소화 |
| **AI 챗봇 면책** | AI 안내가 부정확할 경우 (예: 잘못된 보일러 조작 안내) | 면책 조항 명시, "긴급 상황 시 119" 안내 항상 포함 |

> Phase 1(친구 숙소 3채)에서는 최소한 개인정보처리방침과 이용약관을 갖추고, Phase 2 전에 법률 검토 1회를 수행한다.

### 11.3 기술 리스크

| 리스크 | 난이도 | 대응 |
|--------|-------|------|
| **AI 챗봇이 규격 기반 부품/비용을 정확히 산출** | 높음 | 초기에는 AI 추천 + 창업자가 수동 검증하는 반자동 구조로 시작. 데이터 쌓이면 자동화 |
| **사진 기반 하자 자동 분류 (Phase 3)** | 매우 높음 | 수백 건의 수리 사진 데이터 축적 필요. Phase 1~2에서 데이터 수집에 집중 |
| **다국어 AI 가이드 품질** | 중간 | GPT 기반 번역 + 숙소별 고유명사(모델명 등)는 원문 유지. 주요 언어(영/중/일) 수동 QA |

### 11.4 피벗/중단 기준

- 친구 숙소 3채 적용 후 본인이 "안 쓰겠다"고 판단하면 컨셉 자체를 재검토
- 지인 10명 제안 후 실제 사용하는 사람이 3명 미만이면 피벗 검토
- 수리 건당 마진이 마이너스로 지속되면 수익 구조 재설계
