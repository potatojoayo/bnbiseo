## 자주 등장하는 주제 (빈도 순)

1. **수리/시설 유지보수** — 보일러, 타일, 배수, 잠금장치, 에어컨, 전구, 배관
2. **비품 구매/관리** — 이불솜, 수건, 건조기, 청소기, 매트리스, 침대, 세탁기
3. **게스트 CS** — 실내 흡연, 신발 착용, 소음, 물품 파손, 추가 인원, 쓰레기
4. **리뷰/별점 관리** — 나쁜 리뷰 삭제, 에어커버 신청, 선제적 사과 전략
5. **가격/수익 전략** — 장박 할인율, 추가 인원 요금, 성수기/비수기 가격
6. **해충/위생** — 바퀴벌레, 날파리, 하수구 냄새, 트랩, 방역 업체
7. **운영 외주화 니즈** — 공동호스트 조건, 전전대, 풀오토 운영 대행(수익의 25% 수준)

## GTM/마케팅 인사이트

### 채널 전략

- **카톡 오픈채팅방이 호스트의 1차 정보 소스** — 방장(임백돌) 관계 확보 시 바이럴 가능
- **방장 승인 하에 업체 홍보가 허용됨** — 에어컨 청소, 방역, 인터넷 설치, 침대 특판 등 이미 올라옴 → 동일 경로 활용 가능
- **파워유저 존재** — 정보 허브 역할하는 유저를 얼리 어답터/앰배서더로 확보하면 영향력 큼
- **2,700명 규모 채팅방 1개로 초기 TAM 확보 가능**

### ICP 세분화

| 세그먼트 | 특징 | 적합도 |
|----------|------|--------|
| 신규 호스트 (1개월 미만) | 질문 폭탄, 에너지 소진 빠름 | 높음 — "지치지 않는 운영" 어필 |
| 부업 호스트 (1~3채) | 본업 있음, 해외출장 중 대응 불가 | **최적** — 핵심 ICP |
| 다채 호스트 (5채+) | 풀오토 대행 니즈, 수익의 25% 대행 지출 | 높음 — 비용 절감 어필 |
| 예비 호스트 | 매물 계약 전, 정보 수집 중 | 낮음 |

### 가격 저항선 참고

- 공동호스트 대행: 수익의 25% 수준 (채팅 내 실거래 기준)
- 에어컨 청소: 업체 광고가 올라올 정도로 수요
- 방역: 정기 월 5만원, 1회 10만원 수준

## 어필 포인트

### 가장 강력한 후크

1. **"해외출장 중 보일러 고장" 시나리오** — 실제 사례. 비엔비서가 있었다면 AI가 보일러 모델 확인 → AS 접수 → 기사 방문까지 자동 처리
2. **"매번 똑같은 질문에 대답하기 지침" 시나리오** — 보일러 사용법, 에어컨, 길 찾기, 쓰레기 분리수거. "오픈한지 한달 안됐는데 벌써 지치네요"가 이를 증명
3. **"비품 규격 모르겠어서 물어봐야 함" 시나리오** — 매번 카톡방에 질문하는 구조. 디지털 트윈 비품 DB로 즉시 조회

### 메시징 키워드 후보

- "부업인데 왜 본업처럼 하시나요?"
- "해외에서도, 새벽에도, 게스트 문의 걱정 없이"
- "숙소 시설 규격, 외우지 마세요. 기록해두세요."
