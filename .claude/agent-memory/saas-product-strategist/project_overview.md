비엔비서(BnBiseo)는 서울 내 에어비앤비 호스트를 위한 공간 관리 대행 서비스.

**핵심 컨셉**: 숙소를 디지털 트윈(Digital Twin)화하여 관리 자동화

**비즈니스 모델 (2026-04-04 확정)**:
- 수익 구조: 구독(40%) + 수리 거래 마진(50%) + 부가 서비스(10%)
- 가격 티어: Standard(49,000원/3채), Pro(99,000원/10채), Enterprise(별도) — Free plan 제거 결정 (2026-04-04)
- 진입 전략: "첫 달 무료 + 첫 수리 출장비 무료 + 30일 환불 보장" (Free plan 대체)
- 유닛 이코노믹스: ARPU 80,000원, CAC 150,000원, LTV 880,000원, LTV:CAC 5.9:1
- 손익분기점: 유료 고객 150~180명

**ICP**: 서울 소재 3~10채 운영 중규모 전업 호스트 (30~50대, 월 수입 300만원+)

**North Star Metric**: 월간 활성 관리 숙소 수 (Monthly Active Managed Properties)

**성장 전략**: PLG 중심 - 게스트 QR 바이럴 루프가 핵심 성장 엔진

**MVP 로드맵**:
- Phase 0 (Q1 2026): 랜딩페이지 + 수요 검증 - 완료
- Phase 1 (Q2 2026, 8주): 핵심 MVP - 디지털 트윈, AI 수리 접수, 게스트 QR 가이드
- Phase 2 (Q3 2026): 다국어, 결제, 리포트
- Phase 3 (Q4 2026~): API 연동, 사진 AI, 지역 확장

**Why:** 부업 에어비앤비 호스트의 시설 관리 시간/비용 부담을 AI와 데이터로 해결
**How to apply:** 기능 우선순위는 수리 접수(전환 드라이버) > QR 가이드(리텐션 드라이버) > 디지털 트윈(기반 인프라) 순
