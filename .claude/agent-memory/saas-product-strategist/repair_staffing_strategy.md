수리기사 확장 전략 결정 (2026-04-04 분석):

**결론**: 단계별 직접 채용 우선 → 100채+ 시 하이브리드 전환

| 단계 | 숙소 수 | 전략 |
|------|---------|------|
| Phase 1~2 | 0~40채 | 창업자 직접 수리 (SOP 수립) |
| 40~50채 | 40~50채 | 첫 기사 계약직 채용 (월 280~320만원) |
| 50~100채 | 50~100채 | 직접 고용 2명 체제 |
| 100채+ | 100채+ | 하이브리드 (핵심 기사 2~3명 + 피크타임 외주) |

**Why:** 수리 마진이 매출의 50%이고, "적정가 + 1회 방문 해결"이 핵심 가치 제안이므로 품질 통제가 사업 모델 자체. 외주 시 마진 구조(기사 60~70% 지급)도 맞지 않음. 디지털 트윈 활용/업데이트도 내부 기사만 제대로 수행 가능.

**How to apply:** 수리 오퍼레이션 관련 기능 설계 시 내부 기사 중심 워크플로우 우선. 50채 돌파 전까지는 채용하지 말고 창업자가 직접 수행하며 SOP 구축에 집중. 손익분기: 50채 시점 월 매출 약 385만원, 기사 1명 인건비 300만원.
